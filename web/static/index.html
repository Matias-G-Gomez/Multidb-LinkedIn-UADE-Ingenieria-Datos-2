Red Profesional Multimodelo

Una red profesional estilo LinkedIn construida sobre cuatro bases de datos. Cada dato vive en la base que mejor se adapta a su forma, y una aplicación en Python las mantiene sincronizadas. Abajo, los 7 casos de uso del proyecto consultados en vivo.

Conectando con las bases… si la demo estuvo inactiva, la primera carga puede tardar alrededor de un minuto.

Arquitectura

Aplicación en PythonAPI con FastAPI que consulta y sincroniza las cuatro bases
PostgreSQL
Usuarios, empresas y empleos, con integridad referencial
MongoDB
Publicaciones y mensajes, con comentarios embebidos
Redis
Rankings en Sorted Sets y conteos en Hashes, en memoria
Neo4j
Grafo de conexiones entre usuarios
